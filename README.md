# YouTalk Blog

Учебный проект по вёрстке блога сервиса YouTalk.

Проект выполнен по макету Figma в рамках задания по frontend-разработке.

Реализованы две страницы:

- `blog.html` — главная страница блога со списком статей;
- `article.html` — страница отдельной статьи с основным контентом, sidebar-блоками и промо-секцией.

## Технологии

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media queries
- БЭМ-нейминг
- Локальное подключение шрифтов
- SVG-иконки
- PNG-изображения

## Что реализовано

- Семантическая HTML-разметка.
- Общие блоки `header` и `footer` для обеих страниц.
- Страница блога с фильтрами, карточками статей и кнопкой «Ещё».
- Страница статьи с хлебными крошками, содержанием, текстовыми блоками, изображениями, упражнениями и sidebar.
- Адаптивная вёрстка под основные размеры экранов.
- Локальное подключение шрифтов Montserrat и Open Sans.
- SVG-иконки и PNG-изображения.
- Hover/focus-состояния для интерактивных элементов.

## Адаптивность

Проект проверялся на следующих ширинах:

- 1440px — desktop;
- 1024px — tablet / small desktop;
- 768px — tablet;
- 414px — mobile;
- 320px — small mobile.

Для мобильных экранов отдельно переработаны:

- сетка карточек блога;
- sidebar на странице статьи;
- футер;
- изображения внутри статьи;
- хлебные крошки;
- форма подписки.

## Особенности реализации

- Для сетки карточек блога используется CSS Grid.
- Для sidebar и футера применяются отдельные адаптивные правила.
- На странице статьи декоративные элементы вынесены в отдельные SVG.
- На мобильных разрешениях лишние декоративные элементы скрываются или перестраиваются.
- На самом маленьком разрешении кнопка отправки формы подписки скрывается, чтобы поле e-mail не ломало футер.

## Запуск проекта

Проект не требует сборки.

Достаточно открыть файл `blog.html` или `article.html` в браузере.

Также можно запустить проект через расширение Live Server в VS Code.
